About DinkyDonk

DinkyDonk is a Poker Tournament Manager and Timer designed to help you organize and time poker tournaments efficiently. It provides an easy-to-use interface for managing players, tracking blinds, and keeping the game running smoothly.

Tournament Timer

  • Shows current and upcoming blinds with animated changes,
  • Shows countdown progress along with animated hours/minutes/seconds progress circles,
  • Shows a rotating message including:
    • Tournament name,
    • Staring players,
    • Total payout,
    • Players to be paid,
    • Players remaining, and
    • Average chipstack (actual and as a multiple of the big blind)
  • Shows chips in play with animation to show when a chips will no longer be needed in the next level (they fade in and out) and animation when the chips in play change
  • The timer screen runs in full screen mode for a more professional look
  • The timer’s background color and text color continuously and gradually changes
  • When the timer is running, the screen will be kept awake (good luck with that using any web-based tool on an Apple device!)

Guided Tournament Creation

Create a new, logical tournament structure in seconds, by entering

  1. Your smallest chip denomination,
  2. The number of players you expect, and
  3. Your desired tournament length

Unlike many other apps, this one uses a curated list of blinds as its starting point, so you won’t see levels like 32/64 or 48/96.

The curated list will create a gradually increasing structure, if possible based on your inputs. If it can’t, it will smartly remove certain levels to try to produce a tournament that meets your specifications.

Tournament Management via the Timer Screen

**Timer Management** - Run timed blind levels and breaks (play/pause, restart level, jump back/forward a level, and reset controls on screen) **Buyin Management** Enter buyins, rebuys, addons, and other prize pool or chips in play additions, all via simple spinner controls **Payouts Management** The paytable is automatically created based on your entries in the structure editor: - Percent of players to be paid, and - Paytable shape (flat, balanced or top heavy) If the paytable is allowed to be over-ridden, it can be edited on the timer screen via spinners for number to be paid and for each place's payout **Bustouts Management** Use the bustouts spinner to record bustouts **Tables Management** Enter the maximum number of players per table and the Tables table shows how many tables of x and x-1 players you should have
