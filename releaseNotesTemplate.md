## Windows

**Download [DinkyDonk for Windows](https://github.com/briansayles/DinkyDonk/releases/download/DinkyDonk-v0.5.0/DinkyDonk_0.5.0_x64-setup.exe)**

DinkyDonk is not yet code-signed on Windows so it will likely show a warning when you open the app for the first time. 

You will likely see a Windows Defender SmartScreen warning. Click "More info" → "Run anyway" to proceed.

## MacOS

**Download [DinkyDonk for macOS (Apple Silicon)](https://github.com/briansayles/DinkyDonk/releases/download/DinkyDonk-v0.5.0/DinkyDonk_0.5.0_aarch64.dmg) or [DinkyDonk for macOS (Intel)](https://github.com/briansayles/DinkyDonk/releases/download/DinkyDonk-v0.5.0/DinkyDonk_0.5.0_x64.dmg)**

DinkyDonk is not yet notarized by Apple on macOS, so it will likely show a warning when you open the app for the first time. 

macOS will likely block the app the first time you open it. You can allow it in one of two ways:

1. Go to System Settings → Privacy & Security, scroll down and click "Open Anyway" next to the DinkyDonk message. Then open the app again and confirm.
2. Run this command in the Terminal:

       xattr -dr com.apple.quarantine /Applications/DinkyDonk.app
