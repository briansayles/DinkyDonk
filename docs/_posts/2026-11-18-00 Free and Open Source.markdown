**FREE AND OPEN-SOURCE FOREVER:** 

This program is 100% free to use and improve

- No cost to use...ever
- No limits...ever
- No signup required...ever
- As open-source software, you are free to view the source code and even edit it for your own use or for distribution as a modified version as long as your modification is offered under the same license as the original (copy-left, AGPL3 or later)
  
The only way I make any money on this project is by users voluntarily [buying me a coffee](https://buymeacoffee.com/briansayles)...I have a small QR code on the timer to publicize this request, which I think is very reasonable

**PRIVACY FIRST**

This program stores all data on the user's PC. No data is ever exposed to the internet.

Even when using the network features (timer view and tournament director's dashboard), all data remains within the local network only.
