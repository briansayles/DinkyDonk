**Dedicated network-accessible Tournament Director's View with Controls**

The program serves a Tournament Director page on the local network, allowing the director to run the tournament from a dashboard on a remote device like a smart phone

- Play, pause, jump levels, reset timer
- Add/remove buyins, addons, rebuys
- Add/remove bustouts
- Edit number to be paid and payout amounts
- Edit max players per table
